# dy 去水印 node.js(仅供学习使用)

### 浏览器访问模式
```bash
npm start
```

然后打开 http://localhost:3000/dy?url=输入从抖音复制的url地址

### 工具模式

```bash
node tool.js //会把无水印视频下载到本地
```

### React 虚拟列表表格示例

```bash
npm start
```

然后访问 http://localhost:3000/virtual-table.html 查看使用 React + react-window 实现的虚拟列表表格演示。
